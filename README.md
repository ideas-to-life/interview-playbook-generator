# Interview Playbook Generator

This repository captures the planning, requirements, and design work for an interview playbook generator.

The goal of the project is to help turn role context, company information, and interview preparation inputs into a polished, tailored playbook that supports stronger interview preparation.

## Repository contents

- requirements-spec.md — the initial product requirements and scope
- spec-refinements.md — refinement notes and follow-up questions
- docs/superpowers/specs/2026-07-29-interview-playbook-generator-design.md — the current design proposal

## Current focus

- define the product experience for generating interview playbooks
- capture a clear technical direction for implementation
- keep the project structured and easy to review through lightweight CI checks
