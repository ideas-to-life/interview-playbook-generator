# Upwork Target Position: Senior Agentic AI Architect — Human + AI Workforce & Multi-Agent Orchestration

## Purpose

Evaluate and, only if qualified, generate an Upwork proposal for this opportunity.

The client has an explicit hard gate: the candidate must have personally designed and implemented AI systems inside a real operating company in production. Do not apply if that requirement cannot be supported by canonical evidence.

## Client Scope

The client wants an architect to audit an existing AI architecture and help create a company-wide AI operating system spanning Sales, Customer Service, Marketing, Operations, Finance, Construction and Management.

The desired model is a human + AI workforce: AI assists humans, then performs work under supervision, with humans acting as approvers, exception handlers, managers and specialists.

The first assignment covers current-state assessment; target master orchestration; agent hierarchy, roles and authority; shared and agent-specific memory; agent-to-agent communication; human approval/escalation and maker/checker controls; duplicate/conflict prevention; durable state, retries, recovery and idempotency; observability, audit trails and performance measurement; permissions/security; workflow classification from human-only through fully automated; automation reliability thresholds; staffing/responsibility redesign; and an implementation roadmap.

## Existing Environment

OpenAI/ChatGPT, Salesforce, Shopify, Dialpad, Google Workspace, GitHub, Vercel and Supabase.

## Preferred Technical Experience

OpenAI Agents SDK, LangGraph, MCP, multi-agent systems, Temporal or Trigger.dev/durable workflows, PostgreSQL/Supabase, Redis/queues, RAG/vector databases, LLM evaluation, LLM observability, API architecture, Salesforce APIs, Shopify APIs, GitHub/CI/CD and Vercel/cloud. n8n, Make and CrewAI are useful but insufficient on their own.

## Screening Questions

1. What real company have you personally helped implement a production multi-agent or AI workforce system for?
2. How many agents/workflows?
3. What parts of the company were affected?
4. What measurable business result did it produce?
5. How would you coordinate 50 agents with shared knowledge but different permissions?
6. How would you prevent conflicting or duplicate agent actions?
7. How would you recover a partially completed workflow after failure?
8. If a 50-person company aims to reach 10–15 people supported by AI, how would you determine automation order, human-only work, reliability thresholds and staffing reduction?
