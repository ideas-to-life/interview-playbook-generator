# Phase 1 Data Model: Upwork Qualification and Proposal Generator

## 1. Upwork Target Context Schema (`config.yaml` / Target Position)

Extends target opportunity configuration to identify Upwork job listings.

```yaml
target_slug: "head-of-ai-upwork"
target_type: "upwork"
opportunity_source: "inputs/upwork-job-description.md"
client_name: "Acme Corp (Confidential)"
character_limit: 5000  # optional client or platform limit
word_count_target:
  min: 350
  max: 500
```

## 3. Proposal Projection Schemas (`out/<target-slug>/`)

### 3.1 Upwork Proposal (`out/<target-slug>/upwork-qualification-report.md`)

Rendered as clean professional prose for direct marketplace submission.

```markdown
# Upwork Proposal: [Target Opportunity Title]

**Qualification Status**: `APPLY` | `CONDITIONAL` | `DO NOT APPLY`
**Proposal Generation**: `allowed` | `allowed_with_conditions` | `blocked`
**Word Count**: [Actual Word Count] (Target: 350-500 words)

> [!IMPORTANT]
> [If CONDITIONAL: Display Open Conditions requiring confirmation]
> [If DO NOT APPLY: Gate Report displaying blocking requirements]

## Proposal Text

### 1. Opening & Problem Understanding
[Clean professional prose demonstrating clear understanding of client's core problem]

### 2. Requirement-to-Proof Mapping
[Clean prose presenting strongest 2-4 matches between client requirements and verified experience]

### 3. Project Snapshots
[Max 3 snapshots: Context → Action → Operational/Business Relevance]

### 4. Proposed Approach
[Sequential process: systems/data → automation candidates → AI vs deterministic vs human → controls → validation]

### 5. Smart Questions
[3-5 strategic questions demonstrating deep problem understanding]

### 6. Call to Action
[Concise invitation for a focused problem-solving discussion]
```
