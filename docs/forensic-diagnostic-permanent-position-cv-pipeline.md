4. Detect Target-Language Leakage

config/target-position/lseg-director-enterprise-architecture.md

and:

out/lseg-director-enterprise-architecture/resume-executive.md

Identify language appearing in the target JD that has migrated into candidate claims.

Classify each instance as:

A. Safe terminology reuse

The candidate genuinely has evidence for the concept and using the target terminology improves discoverability.

B. Evidence-supported paraphrase

The wording differs from the source evidence but preserves its scope and meaning.

C. Semantic amplification

The target terminology strengthens or broadens an evidence-supported fact.

D. Unsupported target-to-candidate transfer

A target requirement has effectively become a claim about the candidate without sufficient evidence.

E. Pure employer language

6. Test the Evidence-Boundary Model

Determine whether the current permanent CV pipeline enforces the following invariants:

Identity invariant

Target tailoring must not redefine the candidate’s professional identity.

Evidence invariant

Every substantive candidate claim must be traceable to candidate evidence.

Scope invariant

Projection must not expand:

* project → enterprise;
* prototype → production;
* advisory → implementation;
* capability → outcome;
* adjacent experience → direct expertise.

Ownership invariant

Projection must not change:

* contributed → led;
* participated → established;
* explored → implemented;
* designed → operated;
* proposed → delivered.

Seniority invariant

Projection must not inflate role seniority or organisational scope.

Quantification invariant

Projection must not invent or strengthen metrics.

Domain invariant

Financial-services experience must not automatically become:

* capital-markets expertise;
* market-data expertise;
* index-management expertise;

unless evidence explicitly supports those claims.

Outcome invariant

A technical capability must not become a demonstrated business outcome without evidence.

Report which invariants currently exist and which are absent.
